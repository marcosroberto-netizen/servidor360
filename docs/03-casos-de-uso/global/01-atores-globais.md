# Servidor 360 — Atores Globais

## 1. Objetivo

Este documento apresenta os atores que interagem com funcionalidades pertencentes ao **núcleo global do Servidor 360**.

---

## 2. Usuário Autorizado

Representa qualquer usuário autenticado no sistema.

Dependendo de seu perfil e permissões, poderá:

- acessar o portal;
- localizar servidores;
- consultar prontuários;
- consultar documentos;
- consultar histórico;
- visualizar pendências;
- acessar funcionalidades disponibilizadas pelos módulos.

---

## 3. Administrador

Responsável pela administração estrutural do sistema.

Principais responsabilidades:

- gerenciar usuários;
- gerenciar perfis;
- gerenciar permissões;
- gerenciar unidades;
- gerenciar setores;
- configurar vínculos de acesso.

O perfil administrativo não deverá possuir acesso automático a informações médico/ocupacionais restritas.

---

## 4. Gestor Autorizado

Representa usuários que possuem permissão para acompanhamento gerencial.

Poderá:

- consultar informações consolidadas;
- acompanhar indicadores;
- consultar situação de processos;
- acompanhar pendências administrativas.

A visão gerencial deverá respeitar os limites de acesso às informações restritas.
